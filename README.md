## 🚀 Key Features Breakdown

### 🎌 1. Supercharged Anime Zone (`.anime`)
- **Interactive Catalogs**: Browse Latest, Trending, Ongoing, TV Series, and Anime Movies.
- **Genre Search**: Filter titles by Action, Adventure, Comedy, Fantasy, Romance, Sci-Fi, and more.
- **Smart AniList Metadata**: Auto-resolves high-resolution official posters via AniList & Kitsu GraphQL, bypassing Cloudflare blocks.
- **Instant Direct Download Links**: Generates instant, high-speed direct download mirrors (Google Drive CDN, FastDL, Cloudflare) with zero waiting time and no file size limits.
- **Direct Playback & Streaming**: Direct links can be opened in VLC Media Player or MX Player for instant online watching without downloading.
- **Search & Quick Flow**: `.anime search <title>`, `.anime info <num>`, `.anime episodes <num>`, and `.anime dl <num>`.

### 🎬 2. Powerful Movie & Web Series Zone (`.movie`)
- **Interactive Catalogs**: Browse Latest, Netflix, 4K Ultra-HD, and Anime titles powered by MoviesDrive API.
- **Genre Filtering**: Browse Action, Crime, Comedy, Drama, Horror, Family, Sci-Fi, Thriller, Romance, and Fight.
- **Full TV Series & Movie Support**: Seamlessly browse full movie qualities or explore multi-season series episode lists.
- **TMDB & Metahub Metadata**: High-resolution official posters, cast, synopsis, genres, and IMDb ratings.
- **Multi-Server Direct Downloads**: Instant direct download servers (Cloudflare R2 / Workers, Google Drive CDN, Pixeldrain) for 1-click max-speed downloading (Chrome, 1DM, ADM).
- **VLC / MX Player Streaming**: Stream any movie or episode directly over network without waiting for huge downloads.
- **No File Size Restrictions**: Works seamlessly for any movie size (from 480p 400MB up to 4K UHD 15GB+).
- **Simple Flow**: `.movie search <name>`, `.movie info <num>`, `.movie episodes <num>` (for series), and `.movie dl <num>`.

### 👮‍♂️ 3. Group Management & Security
- **Anti-Link Shield**: Automatically detects and deletes invite links (`.antilink`).
- **Anti-Badword**: Filters vulgar words and warns/removes offenders (`.antibadword`).
- **Anti-Bot Detection**: Real-time detection and ejection of rogue automated bots (`.antibot`).
- **Anti-Tag Protection**: Restricts unwanted `@everyone` mentions (`.antitag`).
- **Anti-Call & PM Blocker**: Rejects calls automatically and blocks unwanted private DMs (`.anticall`, `.pmblocker`).
- **Anti-Delete**: Captures and alerts when group participants delete messages.
- **Admin Moderation**: Kick, ban, promote, demote, mute, unmute, warn, and member warning counters.
- **Tagging Tools**: `.tagall`, `.hidetag`, `.tagnotadmin`, and `.groupstatus`.
- **Custom Welcome & Goodbye**: Interactive greeting messages with customizable cards.

### 📥 3. High-Speed Media Downloader
- **YouTube Downloader**: High-quality MP3 audio download (`.song`, `.play`) and 720p/1080p MP4 video download (`.video`, `.ytmp4`).
- **Spotify**: Search and stream tracks directly from Spotify (`.spotify`).
- **Instagram**: Reels, posts, and carousel downloader with high-speed mirrors (`.instagram`, `.igs`).
- **TikTok**: HD watermark-free video downloads and image slide audio bundles (`.tiktok`).
- **Facebook & Twitter (X)**: Fast direct MP4 reel/video download (`.facebook`, `.twitter`).

### 🤖 4. AI & Creative Studio
- **ChatGPT & Gemini Integration**: Instant conversational responses and answers to queries (`.ai`, `.gpt`, `.gemini`).
- **Text-to-Image Generation**: Ultra-detailed AI image creation powered by Flux and Sora models (`.imagine`, `.flux`, `.sora`).
- **Interactive Chatbot**: AI persona with dynamic slang, natural banter, and conversational responses (`.chatbot`).

### 🎨 5. Image & Sticker Processing
- **Instant Sticker Maker**: Convert images or short clips to animated WhatsApp stickers (`.sticker`).
- **Sticker Cropping & Exif Editor**: Crop stickers, edit author/packname metadata (`.crop`, `.take`).
- **Telegram Sticker Importer**: Import complete Telegram sticker sets directly into WhatsApp (`.tgsticker`).
- **Photo Enhancer (Remini)**: Restore and enhance low-resolution images (`.remini`).
- **Background Remover**: Remove photo backgrounds automatically (`.removebg`).
- **Blinking Text Stickers**: Generate flashing multicolor animated stickers with FFmpeg (`.attp`).
- **Image Blur & Emojimix**: Custom image blurring and emoji-merging engine (`.blur`, `.emojimix`).

### 🎮 6. Interactive Games & Fun
- **Tic-Tac-Toe**: Multiplayer game on WhatsApp grid (`.tictactoe`).
- **Hangman**: Word puzzle game (`.hangman`, `.guess`).
- **Trivia & 8-Ball**: Quiz questions and fortune telling (`.trivia`, `.8ball`).

- **Social Fun**: `.ship`, `.character`, `.wasted`, `.simp`, `.flirt`, `.shayari`, `.compliment`, `.insult`.

### 🔤 7. Textmaker & Styling (18+ Styles)

### ⚙️ 8. Bot Automation & Performance
- **Pairing Code Authentication**: Link effortlessly using WhatsApp Pairing Code without camera scanning.

## 🛠️ Installation & Deployment

### 🖥️ Option 1: Linux VPS / Ubuntu Setup

```bash
# 1. Update system packages
sudo apt update && sudo apt upgrade -y

# 2. Install Node.js 20+ and build tools
curl -fsSL https://deb.nodesource.com/setup_20.x | sudo -E bash -
sudo apt install -y nodejs ffmpeg git build-essential

# 3. Clone Stark Bot MD repository
git clone https://github.com/pujeshreddy/StarkBot-MD.git
cd StarkBot-MD

# 4. Install dependencies
npm install

# 5. Start the bot
npm start
```

### 📱 Option 2: Pairing Code Link

1. Start the bot using:
   ```bash
   node index.js
   ```
2. When prompted in terminal, enter your WhatsApp number with country code (e.g. `919603298365`).
3. You will receive an 8-character pairing code:
   ```
   Your Pairing Code : XXXX-XXXX
   ```
4. Open **WhatsApp** > **Settings** > **Linked Devices** > **Link a Device** > **Link with phone number instead**.
5. Enter the code. Your session is saved securely in the `session/` folder!

### 🐳 Option 3: Docker Deployment

```bash
# Build the Docker image
docker build -t starkbot .

# Run the container
docker run -d --name starkbot-md --restart always starkbot
```

### ☁️ Option 4: Deploy on Railway / Render / Pterodactyl Panel
1. Fork [pujeshreddy/StarkBot-MD](https://github.com/pujeshreddy/StarkBot-MD).
2. Connect your repository to Railway or Render.
3. Set Environment Variables:
   - `MAX_RAM_MB`: `1024`
   - `NODE_ENV`: `production`
4. Build command: `npm install`
5. Start command: `npm start`

```javascript

  packname: 'Stark Bot MD',
  author: 'pujeshreddy',
  botName: "Stark Bot MD",
  botOwner: 'pujeshreddy',
  ownerNumber: '919603298365', // Your number with country code
  commandMode: "public",       // "public" or "private"
  maxRamMB: 1024,              // Memory ceiling
  version: "3.0.8",
  updateZipUrl: "https://github.com/pujeshreddy/StarkBot-MD/archive/refs/heads/main.zip",
};
```
